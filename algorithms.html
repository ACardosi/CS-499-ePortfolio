Artifact Description

InventoryTracker is an Android application developed using Java and SQLite. It provides inventory management functionality, including adding, editing, deleting, searching, sorting, and identifying low-stock items.

I selected this application to demonstrate how algorithms and data structures can support practical inventory management operations.

Enhancement Overview

This enhancement focuses on the application's inventory-processing functionality and the organization of inventory records.

Inventory Management Logic

InventoryTracker uses inventory objects to represent records containing an item name, quantity, description, and identifier. Organizing records as objects makes them easier to process and display.

Sorting

The InventoryManager component provides inventory sorting functionality. Sorting allows users to organize inventory records and locate information more easily.

Searching and Low-Stock Identification

The application provides functionality for finding inventory records and identifying items with low quantities. These operations demonstrate how record selection can support inventory decisions.

Design Considerations

Algorithm selection involves considering correctness, readability, efficiency, and maintainability. An inventory application should produce consistent results while remaining easy to extend and test.

Course Outcome Alignment

This artifact relates to the course outcome involving the design and evaluation of computing solutions using algorithmic principles and appropriate computer science practices.

It also illustrates the importance of selecting data representations and processing techniques that support the application's requirements.

Reflection

Working with inventory-processing logic helped strengthen my understanding of how data structures and algorithms contribute to software functionality.

This work reinforced the importance of evaluating how data is organized, how records are processed, and how design choices affect the maintainability of an application.
