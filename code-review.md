# Code Review

As part of my Computer Science Capstone, I conducted a code review of my
InventoryTracker mobile application. The review examines the existing
application and identifies opportunities for improvement in three key
areas of computer science:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases

The code review discusses the strengths and weaknesses of the original
application and outlines the enhancements planned for my final
ePortfolio.
